# Gerador de Resumo de Código em Python

Projeto em que o usuário envia um arquivo `.py` e o sistema analisa o código automaticamente com apoio de IA.

## ✨ Funcionalidades

O sistema pode gerar:

- resumo do que o código faz
- lista de funções/classes encontradas
- possíveis erros ou melhorias
- explicação simples para iniciantes
- documentação automática

## 🧰 Tecnologias

- Python
- FastAPI ou Flask
- IA/API de linguagem
- SQLite para salvar histórico

## 🚀 Exemplo de uso

Entrada:

> Usuário envia um arquivo Python.

Saída esperada:

> “Esse código cria um sistema de cadastro, possui 3 funções principais e pode melhorar a validação de dados.”
